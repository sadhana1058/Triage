# Test Settings — Activation and Expiry

## How long do tests stay active?

Tests in HackerRank remain active indefinitely unless a start date and end date/time are explicitly set. Without these settings, tests do not expire automatically.

## Setting a test expiry (start and end dates)

To set expiration times, specify a start and end date/time in the test settings. After the expiration date/time:

- Invited candidates cannot access the test.
- The "Invite" button is disabled; no new invitations can be sent.

### Steps to check or change expiration settings

1. Go to the test's **Settings** tab.
2. Select the **General** section.
3. Update the **Start date & time** and **End date & time** fields as needed.
4. To keep the test active indefinitely, clear these fields by clicking the clear icon (X).

If the test has an expiration set, adjust these settings to re-enable new invitations.

## Why candidates may not receive invitations

If people assigned to a test have not received activation emails or cannot access the test, check the following:

- **Test expiry**: If a start/end date was set and the period has passed, invitations cannot be sent. Clear the expiry date or set a new end date.
- **Candidate already has a HackerRank account**: Candidates with existing accounts receive an invitation email with a direct link. If they did not receive it, ask them to check spam/junk folders.
- **Test link sharing**: If using a public test link instead of individual invitations, ensure the link has not expired.
